# Alli Hodgson — Work Portfolio

A static portfolio site featuring six case studies across process design, quality systems, operational communication, training, enablement, and enterprise change.

## Structure

- `index.html` — portfolio homepage
- `work/` — individual case-study pages and shared styling
- `alli-hodgson-portrait.jpeg` — profile image
- `Alli_Hodgson_Work_Samples.pdf` — downloadable complete portfolio

The site uses plain HTML and CSS and can be hosted directly with GitHub Pages.
